# Portfolio

A minimal, high-performance developer portfolio built with React, TypeScript, and Tailwind CSS.

## Tech Stack

* **Core:** React, TypeScript, Vite
* **Styling:** Tailwind CSS
* **Icons:** react-icons
* **Deployment:** Vercel

## Development

Install dependencies:
```bash
npm install

Start dev server:
```bash
npm run dev

Build for production:
```bash
npm run build
